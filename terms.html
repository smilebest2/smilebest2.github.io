利用規約

「しくみの一分 自動投稿」を管理者本人が利用する際の条件です。

1. 利用目的と対象

本アプリは、管理者本人のYouTubeチャンネル「しくみの一分」で、約1分の図解ショート動画を運用するための個人用アプリです。一般利用者向けの登録サービスではありません。利用にあたっては、この規約とプライバシーポリシーを確認してください。

2. 接続するチャンネル

管理者が正当な管理・投稿権限を持つチャンネルのみを接続します。Googleの認可画面で権限を確認して同意し、取得したチャンネル情報を使って投稿先を照合します。

3. 投稿内容と公開設定

管理者は、動画・音声・画像・文章等の著作権その他の権利を確認し、タイトル、説明文、投稿先、公開範囲を管理します。投稿機能の有効化後は、指定した動画とメタデータをYouTube Data APIへ送信します。

現在、API認証とチャンネル照合は検証済みですが、API経由の投稿と日次運用は検証段階です。将来の無制限利用、永久無料、投稿の成功や指定時刻の公開は保証しません。

4. 外部サービスの利用条件

本アプリはYouTube API Servicesを使用します。本アプリを利用する管理者は、YouTube利用規約に拘束されることに同意するものとします。また、Google APIs利用規約、YouTube API Services利用規約および関連するポリシーに従います。

5. 禁止する行為

不正アクセス、権限のないチャンネルの接続、認証情報の不正利用、著作権・プライバシー等の権利侵害、外部サービスの制限を不正に回避する行為を禁止します。

6. 中断・変更

Google、YouTube、OpenAI Sites、Cloudflare等の障害・仕様変更・利用上限・認可の失効などにより、連携や投稿が中断する場合があります。管理者は実行結果を確認し、必要に応じて運用を停止・修正します。

7. データの取り扱いと連絡先

データの利用・保存・認可解除・削除方法はプライバシーポリシーに従います。お問い合わせは、Google認可画面でアプリ名「しくみの一分 自動投稿」を選択した際に表示されるサポートメール宛にお願いします。
