プライバシーポリシー

「しくみの一分 自動投稿」の情報の取り扱いについて説明します。

1. 目的と利用対象

本アプリは、管理者本人のYouTubeチャンネル「しくみの一分」の約1分の図解ショート動画を運用する個人用アプリです。YouTube API Servicesを利用します。一般利用者の登録は受け付けていません。

2. 取得・処理する情報と利用目的

OAuthクライアントID・クライアントシークレット
GoogleへのOAuth認証要求でアプリを識別し、認証処理を行うために扱います。
更新トークン・一時的なアクセストークン
管理者の同意した範囲で認証を更新し、YouTube Data APIへアクセスするために扱います。
チャンネルID・名称・ハンドル
接続したチャンネルを識別し、投稿先が正しいか照合するために扱います。
動画・メタデータ・投稿結果
投稿機能を有効化した場合に扱います。動画、タイトル、説明文、公開設定を投稿に使用し、返された結果を投稿状況の確認に使用します。API投稿と日次運用は現在未検証です。

3. 保存方法とアクセス制限

クライアントシークレットと更新トークンは、非公開の連携処理で暗号化して保存します。暗号鍵はサーバーのシークレット設定で管理します。認証情報を公開ページや公開リポジトリに掲載しません。

本アプリは管理者本人用であり、保存情報を一般利用者へ公開する機能は設けません。一時的なアクセストークンはAPIへのアクセスに使用します。その他の情報の個別の保存期間やバックアップ保持期間は、本ページでは未確認の数値を断定しません。

4. 外部サービスへの送信

  • Google・YouTube：認証の更新に必要な情報とAPI要求を送信します。投稿機能の有効化後は動画とメタデータも送信します。投稿した内容の公開範囲はYouTube側の公開設定に従います。
  • OpenAI Sites・Cloudflare：非公開の連携ツールの実行・保存基盤として利用し、連携処理に必要な情報を扱います。
  • GitHub Pages：この公開説明サイトの配信に使用します。このサイトでOAuthトークン等を入力・収集することはありません。配信サービスは通信に伴うIPアドレス等を各サービスの方針に従って処理する場合があります。

この公開サイト独自のアクセス解析・広告・外部フォント・追跡スクリプトは設置せず、Cookieやブラウザー保存領域を操作するコードも使用しません。

Google側の情報の取り扱いはGoogleプライバシーポリシーもご参照ください。

5. Googleユーザーデータの利用制限

Google APIから受け取る情報の使用および他のサービスへの転送は、Limited Use（制限付き使用）要件を含むGoogle API Services User Data Policyに従います。

情報は、このページで説明する認証更新、チャンネル照合、動画投稿と投稿状況確認のために使用します。Googleユーザーデータを販売、広告配信、汎用AIモデルの学習に使用しません。連携基盤への送信は、同意された機能の提供に必要な範囲に限ります。人による閲覧も、管理者本人による利用、明示的な同意、安全確保や法令上必要な場合など、同ポリシーで認められる範囲に限定します。

6. 保存期間・認可解除・削除方法

連携継続のための認証情報は連携に必要な間保持し、不要になった情報は管理者が削除対象として確認します。現時点で一律の日数による自動削除機能はありません。

Google側の認可を取り消す

Googleアカウントの接続管理で「しくみの一分 自動投稿」を選択し、アクセス権を取り消せます。これはGoogle APIへのアクセス許可を解除する操作です。

アプリ側の保存情報を削除する

認可解除だけで、アプリ側の保存情報が自動的に消去されるとは限りません。管理者は非公開連携処理の保存先で、対象の認証情報・チャンネル情報・保存済みの投稿関連情報を個別に確認し、手動で削除します。削除に関する依頼・問い合わせは、下記のサポートメール宛にお願いします。公開サイトには自動削除ボタンはありません。

YouTubeへ投稿済みの動画は、アプリ側の情報削除とは別に、管理者がYouTubeで削除・公開設定変更を行います。

7. 変更とお問い合わせ

処理内容や外部サービスの変更に応じて、本ページを更新し、最終更新日を明示します。

お問い合わせ・削除のご相談は、Googleの認可画面でアプリ名「しくみの一分 自動投稿」を選択した際に表示されるサポートメール宛にお願いします。秘密情報やトークンを問い合わせ本文へ記載しないでください。
